# GitHub Pages Starter

A tiny static website made to test GitHub hosting. It uses plain HTML, CSS and JavaScript—no build tools or dependencies required.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait a minute or two. GitHub will show your published site URL in the Pages section.

For a project repository, the URL is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`. For a repository named `YOUR-USERNAME.github.io`, the URL is usually `https://YOUR-USERNAME.github.io/`.

## Test it

- The page should display “It works.”
- Click **Test the button**. The message should change, confirming JavaScript loaded.
- Resize the browser to check the responsive layout.

You can edit the text in `index.html` and the design in `style.css`.
